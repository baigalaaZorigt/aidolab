Нууцлалын бодлого

Хүчин төгөлдөр болсон: 2026 оны 10-р сарын 17

AIDO Lab Mongolia («бид») нь aidolab.mn болон app.aidolab.mn («үйлчилгээ»)-ийг ажиллуулдаг. Энэ бодлого нь бид ямар мэдээлэл цуглуулж, юунд ашиглаж, хэрхэн хамгаалдгийг тайлбарлана.

1. Бидний цуглуулдаг мэдээлэл

  • Бүртгэлийн мэдээлэл: нэр, имэйл хаяг, нууц үг (зөвхөн нэг талын шифрлэсэн hash хэлбэрээр).
  • Google-ээр нэвтрэх үед: таны Google бүртгэлийн нэр, имэйл хаяг, имэйл баталгаажсан эсэх. Бид зөвхөн openid email profile эрх хүсдэг. Gmail, Drive, холбоо барих хүмүүс зэрэг өөр мэдээлэлд хандахгүй.
  • GitHub-ээр нэвтрэх үед: GitHub хэрэглэгчийн нэр, ID, баталгаажсан имэйл, мөн таны public repo-уудын жагсаалт. Бид зөвхөн read:user user:email эрх хүсдэг тул private repo, кодыг уншиж, өөрчилж чадахгүй.
  • Шалгуулсан repo: таны оруулсан public GitHub repo-г бид түр татаж, зөвхөн уншиж шалгана. Кодыг ажиллуулахгүй. Шалгалтын үр дүн (оноо, илэрсэн асуудал) хадгалагдана. Нууц түлхүүр илэрвэл зөвхөн далдалсан хэлбэрээр (жишээ нь sk-a…******) хадгална.
  • Hosting: deploy хийсэн апп-ын тохиргоо, орчны хувьсагчид (утгыг нь дэлгэцэнд хэзээ ч харуулахгүй; апп руу AWS-ийн шифрлэгдсэн хадгалалтаар дамжуулна), домэйн, deploy-ийн лог.
  • Холбоо барих форм: таны бичсэн нэр, утас, төслийн холбоос, тайлбар.
  • Системийн лог: нэвтрэлт, шалгалт, deploy зэрэг үйлдлийн цаг болон IP хаяг (аюулгүй байдлын зорилгоор).
  • Cookie: зөвхөн нэвтрэлтийг хадгалах (session) болон хуурамч хүсэлтээс хамгаалах (CSRF) шаардлагатай cookie. Зар сурталчилгааны болон гуравдагч талын хянах cookie ашиглахгүй.

2. Мэдээллийг юунд ашигладаг вэ

  • Таныг нэвтрүүлэх, бүртгэлийг тань удирдах.
  • Repo-г шалгаж, үр дүн болон засах зөвлөгөөг харуулах.
  • Таны апп-ыг байршуулж (deploy), ажиллуулах.
  • Холбоо барих хүсэлтэд хариулах, тусламж үзүүлэх.
  • Үйлчилгээний аюулгүй байдлыг хангах, буруу ашиглалтаас сэргийлэх.

Бид таны мэдээллийг худалдахгүй, зар сурталчилгаанд ашиглахгүй, AI загвар сургахад ашиглахгүй.

3. Google хэрэглэгчийн мэдээлэл

Google-ээс авсан мэдээллийг (нэр, имэйл) зөвхөн таныг нэвтрүүлж, бүртгэл үүсгэхэд ашиглана. Энэ мэдээллийг ашиглах, хадгалах, дамжуулах нь Google API Services User Data Policy, түүний дотор Limited Use шаардлагыг дагана. Google-ийн нэвтрэх token-ийг нэвтэрсний дараа хадгалахгүй.

4. Гуравдагч талын үйлчилгээ

  • Amazon Web Services (Токио, Япон): сервер, өгөгдлийн сан, файл хадгалалт.
  • Anthropic (Claude): шалгалтын илэрцийг монголоор тайлбарлахад ашиглана. Зөвхөн илэрсэн асуудлын жагсаалтыг (нууц утгыг далдалсан) илгээнэ. Таны бүх кодыг илгээхгүй.
  • OSV (Google): сангийн нэр, хувилбарыг илгээж, эмзэг байдлыг шалгана.
  • GitHub, Google: нэвтрэлт болон repo жагсаалт.
  • Let's Encrypt: SSL сертификат.

5. Хадгалах хугацаа

Бүртгэл идэвхтэй байх хугацаанд мэдээллийг хадгална. Бүртгэлээ устгуулахыг хүсвэл бид таны бүртгэл, шалгалтын түүх, deploy хийсэн апп, орчны хувьсагчдыг устгана. Өгөгдлийн сангийн нөөц хуулбар 14 хоногийн дараа автоматаар устдаг.

6. Хамгаалалт

Бүх холболт HTTPS-ээр шифрлэгдсэн. Нууц үг hash хэлбэрээр хадгалагдана. Апп-ын орчны хувьсагчдыг AWS-ийн шифрлэгдсэн хадгалалтаар (SSM SecureString) дамжуулж, хэрэглэгчийн интерфейсэд утгыг нь харуулахгүй. Хэрэглэгчийн апп тус бүр тусгаарлагдсан орчинд ажиллана. Шалгуулсан кодыг манай сервер дээр хэзээ ч ажиллуулахгүй.

7. Таны эрх

Та өөрийн мэдээллийг харах, засах, устгуулах, GitHub/Google холболтоо салгах эрхтэй. GitHub холболтыг GitHub → Settings → Applications хэсгээс, Google холболтыг myaccount.google.com/permissions хаягаар хүссэн үедээ цуцалж болно.

8. Хүүхдийн мэдээлэл

16 нас хүрээгүй хэрэглэгч эцэг эх, асран хамгаалагчийн зөвшөөрөлтэйгээр үйлчилгээг ашиглана.

9. Өөрчлөлт

Энэ бодлогыг шинэчилбэл энэ хуудсан дээр огноог нь өөрчилж нийтэлнэ. Томоохон өөрчлөлтийг бүртгэлтэй хэрэглэгчдэд имэйлээр мэдэгдэнэ.

10. Холбоо барих

Нууцлалтай холбоотой асуулт, хүсэлтээ info@aidolab.mn хаягаар илгээнэ үү.
